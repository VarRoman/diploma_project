

\begin{unnumbered}

\subsection{1. НАЙМЕНУВАННЯ ТА ОБЛАСТЬ ЗАСТОСУВАННЯ}
В цьому технічному завданні охоплено опис розробки та впровадження програмно-алгоритмічного комплексу комп'ютерного
зору для аналітики волейбольних подій, завдяки аналізу позиції м'яча в тривимірному просторі

Областю застосування цієї системи є спортивна аналітика, автоматизований збір статистики тренувальних та змагальних
процесів у волейболі, а також інструментарій для тактико-технічного аналізу та оцінки кінематики рухів гравців
тренерськими штабами аматорських і професійних ліг.

\subsection{2. ПІДСТАВИ ДЛЯ РОЗРОБКИ}

Першою підставою для розробки є завдання на виконання бакалаврської кваліфікаційної роботи рівня «бакалавр комп'ютерної
інженерії», який був затверджений факультетом "Інформатики та обчислювальної техніки" кафедрою обчислювальної техніки
Національного технічного Університету України «Київський Політехнічний інститут ім. Ігоря Сікорського».

А другою підставою є необхідність створення актуальної мобільної та обчислювально доступної альтернативи дорогим
багатокамерним стаціонарним комплексам, що здатна функціонувати на основі монокулярних відеопотоків із побутових камер.

\subsection{3. МЕТА ТА ПРИЗНАЧЕННЯ РОЗРОБКИ}

Метою розробки є створення високоточної системи для розрахунку кінематичних метрик волейбольного м'яча(тривимірної
траєкторії, пікової швидкості атакуючої дії, точок відскоку) з усуненням апаратних шумів та впливу розмиття рухом.

Призначенням розробки є програмний комплекс для автоматизації процесу перетворення сирих двовимірних відеоданих у
фізичну метричну систему тривимірного простору з використанням сучасних методів глибокого навчання та ймовірнісного
нелінійного згладжування.

\subsection{4. ДЖЕРЕЛА РОЗРОБКИ}

Джерелами розробки є
\begin{itemize}
    \item наукова й технічна література з методів комп'ютерного зору, перспективної просторової геометрії,
    багатокритерійного трекінгу та теорії оптимального оцінювання станів динамічних систем;
    \item Офіційна документація алгоритмів об'єктної детекції архітектури \gls{YOLO};
    \item Відкриті програмні бібліотеки та фреймворки (OpenCV, Ultralytics, FilterPy, NumPy, PyTorch).
\end{itemize}


\subsection{5. ТЕХНІЧНІ ВИМОГИ}
\subsubsection{5.1. Вимоги до вхідних даних}

\begin{itemize}
    \item Система повинна обробляти відеопотоки стандартних форматів (MP4, AVI) з роздільною здатністю не менше 1920x1080 пікселів.
    \item Мінімально допустима частота кадрів для коректного розрахунку динаміки – 50 FPS(з використанням методів програмного вирівнювання VFR у CFR).
\end{itemize}

\subsubsection{5.2. Вимоги до функціональних модулів}
\begin{itemize}
    \item \textit{Модуль детекції:} Використання anchor-free моделі \gls{YOLO}(рівня yolo26m) зі збільшеним розміром вхідного тензора (imgsz=1088) для детекції дрібних об'єктів.
    \item \textit{Геометричний модуль:} Реалізація перетворення 2D-пікселів у 3D-промені(Ray Casting) на основі алгоритму просторового калібрування \gls{PnP}(solvePnP) із механізмом інверсії координатних осей під балістичну модель.
    \item \textit{Модуль трекінгу:} Адаптований алгоритм 3D ByteTrack з двостадійною асоціацією даних та використанням статистичної відстані Махаланобіса замість \gls{IoU}.
    \item \textit{Модуль фільтрації:} Нелінійне згладжування траєкторій за допомогою багатомодельної архітектури \gls{IMM}у поєднанні з сигма-точковими фільтрами Калмана (\gls{UKF}). Наявність захисту від обчислювальних аномалій(вибух коваріації).
\end{itemize}

\subsubsection{5.3. Вимоги до апаратної частини}

\begin{itemize}
    \item Операційна система: Windows 10/11 або дистрибутиви Linux(Ubuntu).
    \item Мова програмування: Python версії 3.11 або вище.
    \item Апаратна частина: багатоядерний центральний процесор (CPU) та графічний прискорювач (GPU) із підтримкою
    технології паралельних обчислень CUDA для забезпечення мілісекундного інференсу нейромережі.
\end{itemize}

\subsection{6. ЕТАПИ РОЗРОБКИ}
\subsubsection{6.1 Аналітичний етап}
Вивчення предметної області, збір власних відеоданих, їх попереднє оброблення та підготовка датасету.
\subsubsection{6.2 Нейромережевий етап}
Проектування архітектури пайплайну, донавчання та валідація моделі \gls{YOLO} на хмарних обчислювальних потужностях.
\subsubsection{6.3 Математичний етап}
Програмна реалізація алгоритмів Ray Casting, конфігурація матриць шуму та переходу для моделей \gls{IMM}-\gls{UKF},
розробка просторового трекера 3D ByteTrack.
\subsubsection{6.4 Інтеграційний етап}
Об'єднання розроблених модулів у єдиний конвеєр, проведення експериментів на реальних ігрових епізодах, отримання
кінематичної статистики.
\subsubsection{6.5 Документаційний етап}
Оформлення вихідного коду, візуалізація графіків результатів та написання тексту пояснювальної записки.
